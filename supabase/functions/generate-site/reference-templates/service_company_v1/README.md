# service_company_v1 — Reference template (INACTIVE)

Premium multi-page service-company template with strong hero, trust sections, service grids, contact page, and FAQ page.

This template started from an HVAC / plumbing / electrical example, but it should be treated as a broad service-business reference:

- electricians
- plumbers
- HVAC companies
- builders
- cleaning companies
- painters
- roofers
- landscaping companies
- other local service businesses

## Important adjustments already made

- the header logo is simplified to plain company name only
- the fake before/after landing-page section has been removed
- the replacement section is more flexible and can be rewritten from real business strengths instead of invented transformations

## Status

Stored in the library for future use. Not wired into the generator yet.

## How it should be used later

When the generator selects a broad service-company niche, it should:

- keep the page structure and overall premium layout
- replace all business-specific copy, phone, email, location, and service labels
- adapt imagery to the actual niche
- keep the trust / service / contact / FAQ structure
- avoid invented case-study claims unless real source material supports them

## Files

- `index.html` — homepage / landing page
